# 띠별 오늘의 운세 — PPTX 생성 프로젝트

신문 「오늘의 운세」 코너용 **띠별 일일 운세 슬라이드(13장)**를 만드는 파이프라인입니다. 월별 원본 엑셀을
받아, 날짜별로 **표지 1장 + 12간지 12장 = 13장**짜리 PowerPoint(`MMDD.pptx`)와 슬라이드 PNG를
생성합니다.

## 산출물 예시

날짜 코드 `0709`(7월 9일)의 슬라이드 샘플입니다.

![슬라이드 예시](5_PNG/0709_png/slide_02.png)

## 환경 요구 (요약)

- Windows + PowerPoint 설치(글꼴 임베드·PNG 내보내기에 COM 자동화 사용)
- 파이썬은 `py -X utf8`만 사용 (python-pptx, Pillow, openpyxl)
- 글꼴 2종: 본문 임베드용 `a아시아명조M`, 검증기 측정용 `KBIZ한마음명조 M`

## 저장소 미포함 자산

원본 엑셀(`1_원본엑셀/`), 디자인 템플릿(`3_템플릿/0511.pptx`), 글꼴 파일, 대량 산출물(`4_PPTX/`,
`5_PNG/*`, `6_ZIP/`)은 저작권·용량 문제로 이 저장소에 포함되지 않습니다. 별도 전달이 필요합니다.
샘플로 `0709` 하루치(`2_스크립트/build_0709.py`, `5_PNG/0709_png/`)만 포함돼 있습니다.
