**"이미지 추출" 단계** — 3단계 파이프라인(운세 변환 → 운세 삽입 → 이미지 추출) 중 글꼴 임베드·PNG
내보내기만 담당한다. 정본은 `PROJECT_GUIDE.md`(워크플로우 §4의 6단계, 완료 체크리스트 §5).
`2_스크립트/`에서 실행한다. PowerPoint 데스크톱 앱 설치가 필요하다(COM 자동화, Windows 전용).

## 인자 해석 ($ARGUMENTS)
공백으로 구분된 MMDD 코드 1개 이상. 없으면 어느 날짜를 처리할지 되묻는다.

## 사전 조건
각 MMDD에 대해 `4_PPTX/MMDD.pptx`가 이미 존재해야 한다. 없으면 "먼저 `/운세삽입 MMDD`부터 실행하라"고
안내하고 그 코드는 건너뛴다.

## 절차 (이 단계에서만 함)
```
powershell -ExecutionPolicy Bypass -File embed_export.ps1 MMDD1 MMDD2 ...
```
→ 각 `4_PPTX/MMDD.pptx`에 글꼴을 임베드(같은 파일에 덮어쓰기)하고 `5_PNG/MMDD_png/slide_01~13.png`
(1500×2362px)를 생성한다. 코드별 `완료`/`실패` 로그와 마지막 `=== 완료 N / 실패 N ===` 요약을 확인한다.

## 완료 확인 (PROJECT_GUIDE.md §5-4)
`MMDD.pptx`를 zip으로 열어 `ppt/presentation.xml`에 `embedTrueTypeFonts="1"` 속성이 있는지 확인한다.

## 범위 밖 (하지 않음 — 다른 명령의 몫)
- 원문 추출·SUMMARIES 작성·qa 수정 → `/운세변환`
- pptx 생성/갱신(`build_MMDD.py` 실행) → `/운세삽입`

## 주의
이 단계 이후 `/운세삽입 MMDD`를 다시 실행하면(SUMMARIES 재작성 등 이유 불문) 임베드가 사라진다.
그런 경우 이 명령을 다시 실행해야 완료 상태다.
